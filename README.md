- **Memory**: 24.0 GB Installed RAM (23.6 GB usable) | 4.0 GB RAM required / 8.0 GB RAM recommended

### Software Requirements
- **Operating System**: Windows 11 Pro 64-bit
- **Development Environment**: PyCharm IDE / Jupyter Notebooks
- **Runtime**: Python 3.10+
