# HVAC and Air Quality Predictive Model

---

## System Used For Development and Software Requirements
### Hardware Requirements
- **System**: Dell Latitude 5410 Laptop | or equivalent
- **Processor**: Intel(R) Core(TM) i7-10810U CPU @ 1.10GHz (1.61 GHz) | or equivalent
- **Memory**: 24.0 GB Installed RAM (23.6 GB usable) | 4.0 GB RAM required / 8.0 GB RAM recommended
- **Storage**: Minimum 1 GB available disk space

### Software Requirements
- **Operating System**: Windows 11 Pro 64-bit
- **Development Environment**: PyCharm IDE / Jupyter Notebooks
- **Runtime**: Python 3.10+
- **Python Libraries**:
  - `pandas`
  - `numpy`
  - `scikit-learn`
  - `ucimlrepo`

---

## Instructions to Run the AI/ML Application

### 1. Environment Setup
Clone the repository and install required packages:
```bash
pip install pandas numpy scikit-learn ucimlrepo
```
### 2. Data Preprocessing
```bash
python preprocess.py
```
### 3. Model Training & Evaluation
```bash
python train_and_evaluate.py
```
### 4. Model Optimization
```bash
python optimize_model.py
```
